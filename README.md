# InBride — лендинг

Статический сайт (HTML/CSS/JS) + одна serverless-функция Vercel для приёма заявок.

```
index.html        — лендинг
styles.css        — стили (mobile-first)
script.js         — меню, фильтр, окно «Детальніше», вышивка, форма
privacy.html      — политика конфиденциальности (шаблон)
oferta.html       — публичная оферта (шаблон)
api/lead.js       — приём заявок → Telegram
images/           — ваши фото в WebP (640 и 1200 px)
og-image.jpg      — превью для соцсетей 1200×630
vercel.json, robots.txt, sitemap.xml, favicon.svg
```

### Как подключить (5 минут)

1. В Telegram откройте **@BotFather** → `/newbot` → получите токен вида `123456:ABC...`.
2. Напишите своему боту любое сообщение (или добавьте его в группу менеджеров).
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}` — это ID чата (у групп он отрицательный).
4. В Vercel: **Project → Settings → Environment Variables** добавьте
   - `TELEGRAM_BOT_TOKEN` = токен
   - `TELEGRAM_CHAT_ID` = ID чата
5. Сделайте **Redeploy**. Отправьте тестовую заявку с сайта.

Если удобнее email или Google Таблица — замените тело `api/lead.js`, фронтенд менять не нужно.

## Деплой на Vercel

- Через GitHub: загрузите папку в репозиторий → Vercel → **Add New Project** → Framework Preset: **Other**, Build Command пусто, Output Directory пусто.
- Или через CLI: `npm i -g vercel` → в этой папке `vercel` → `vercel --prod`.

Локально без Vercel сайт открывается, но форма будет показывать ошибку (нет `/api`). Для полной проверки: `vercel dev`.

## Что заменить перед запуском

Найдите поиском по файлам:

- `[уточнити]` — условия доставки, оплаты, сроков, возврата, ответы в FAQ
- `[ціна]` — цены в карточках (`index.html`, атрибут `data-price` и текст в `.price`)
- `[ваш-домен]` — в `index.html` (canonical, og:url, og:image), `robots.txt`, `sitemap.xml`
- `[+380 XX XXX XX XX]`, `tel:+380000000000`, `[email…]`, `hello@example.com`, `instagram.com/` — контакты в подвале и кнопке отзывов
- `ФОП [...]`, `[код]`, `[юридична адреса]` — данные продавца в подвале и юр. страницах
- Оттенки и длины в карточках — **демо**. Правьте `data-shades` и `data-lengths` у каждого `<li class="product">`; цвета кружочков — в `SHADE_COLORS` в начале `script.js`. Когда замените — удалите строку `.demo-banner` в `index.html`.
- Заполнители фото: категории «Рукавички» и «Прикраси для волосся», блок отзывов.
- Тексты `privacy.html` и `oferta.html` согласуйте с юристом.

## Как добавить товар

1. Сохраните фото в `images/` в двух размерах: `имя-640.webp` и `имя-1200.webp` (ширина 640 и 1200 px).
2. Скопируйте любой `<li class="product">…</li>` в `index.html`, поменяйте `data-*`, `<img>`, название и цену.
3. `data-category`: `veil` (фати), `cape` (накидки й кейпи), `gloves` (рукавички), `hair` (прикраси для волосся).
   Кнопка фильтра появится сама, когда в категории будет хотя бы один товар.
